QUICK GUIDE

開始你的第一批下載

  1. 匯入 Excel 或手動新增

    選取工作表後自動偵測法院與右側三欄。資料列從 1 起算，欄位使用 A、B、AA 等英文字母。重複案號會合併；錯誤資料列會列在執行紀錄。

  2. 整理下載順序

    點選表格標題或使用多欄位排序。搜尋僅篩選顯示；下載會包含全部案號，依目前清單順序執行。勾選案號用於刪除清單項目。

  3. 選擇格式並開始下載

    下載目前搜尋條件符合的刑事判決。歷審支援 TXT 與 PDF，不適用 JSON；網站只提供另一種格式時，會依原有邏輯轉存並記錄。

  4. 查看結果與儲存位置

    下載檔案另存於指定位置下的新資料夾。結果分別統計檔案數、無結果案號及錯誤項數，詳細原因可匯出。API JSON 沿用本機既有的 API 設定。
